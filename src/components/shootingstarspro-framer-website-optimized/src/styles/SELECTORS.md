# Selectors

What you named a layer in Framer, and the selector that reaches it in CSS. Generated from shootingstarspro-framer-website; regenerated on every conversion.

Class names are Framer's and must stay as they are — they are what the stylesheet binds to. To restyle something, find its layer below and write a rule against that selector in `src/styles/custom.css`, which is last in the cascade and survives re-conversion.
