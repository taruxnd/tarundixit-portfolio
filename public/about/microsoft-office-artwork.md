# Microsoft office illustration

Stylized miniature of DLF Downtown Block 2, Gurugram, where Microsoft's office is located. This is an illustration, not an architectural rendering.

Architecture reference: [DLF's official property photographs](https://www.dlf.in/offices/gurugram/dlf-downtown), specifically `property_image_684023783a786.jpg`.

Location verified against [Microsoft India's contact page](https://www.microsoft.com/en-in/about/contact-us): DLF Downtown, Level 8, Block 2.

Generated with the built-in image generation tool on 25 October 2026. The photo supplied the building's shape, blue glass, bronze facade strips, and upper-corner Microsoft signage. The previous portfolio landmark supplied only the miniature illustration style. Output exported to transparent WebP at 640 × 426.

Revised to a straight-on front elevation with a level roof and base, parallel verticals, and no visible side facade.
